# Version history

This timeline comes from the Windows EXE for each version. The repository starts with the v7 source. It does not contain invented commits for earlier versions. Screenshots use sample data.

## v7 (app version 0.1.6) · Current Windows download

The Home screen now focuses on the connection, the live preview, and the OMP extension. A gear opens a separate Settings screen. Settings holds the Discord presence controls, a local profile picture, and OMP, black, and white themes. The picture appears only in this app. It cannot change your Discord account avatar.

The optional **Start with OMP** setting lets the OMP extension start the portable Windows app when an OMP session opens. It is off by default. The app saves its EXE path after you run it. Restart OMP after you enable this setting. The app does not start when Windows starts.

## v6 (app version 0.1.5)

The first full dashboard redesign added an OMP purple theme, black and white themes, a GitHub button, and a **Made by 08** credit. The app also began reading saved OMP session metadata for project and chat details when live extension data was not available.

## v5 (app version 0.1.4)

The OMP extension began sharing the project name and optional chat title. The app added separate title controls and an optional username. It also began updating known older copies of the extension without replacing edited copies.

## v4 (app version 0.1.3)

The app began detecting the OMP process. It could show that OMP was running while it waited for extension data.

## v3 (app version 0.1.2)

The setup card stopped showing after the OMP extension was installed. The status text also began guiding users who needed to start or restart OMP.

## v2 (app version 0.1.1)

The app included the public OMP Discord application ID. Users no longer had to create a Discord application or paste an ID into Settings.

## v1 beta (app version 0.1.0)

The first Windows build shared the OMP model, effort level, and elapsed time through Discord. It had a live preview and an OMP extension installer. Users still had to supply their own Discord application ID.
